# 公众号图文配图指南

## 目标

把文章从“纯文字初稿”推进到“图文成稿”。

配图不是装饰，而是承担三类任务：

1. 提高点击：首图/封面图要让选题张力一眼成立。
2. 帮助理解：文内图要解释关键概念、流程、对比或案例。
3. 加强记忆：每张图应对应文章中的一个明确观点。

## 默认图片规格

如果用户没有特别指定，按以下规格设计：

- 首图/封面图：16:9，横版，适合公众号头图与社交分享。
- 文内配图：4:3 或 3:2，横版优先，适合正文阅读。
- 信息图：竖版或方图均可，但要避免小字密集。
- 社交分享图：1:1，适合朋友圈、群聊预览或海报。

## 图片数量

默认生成：

- 首图/封面图：1 张
- 文内配图：2-4 张
- 社交分享图：可选 1 张

如果文章短于 1200 字，通常 1 张首图 + 1-2 张文内图即可。
如果文章超过 2500 字，可增加到 4-6 张，但每张都必须有明确用途。

## 设计流程

### 1. 提取可视化节点

从文章中提取这些内容：

- 核心冲突：谁和谁之间的张力是什么
- 关键转折：文章在哪里改变读者判断
- 具体案例：有没有可画成场景的细节
- 方法步骤：有没有流程、清单、对比表
- 情绪峰值：最适合用图像加强的段落

### 2. 制定图片清单

每张图都要包含：

- 文件名
- 图片类型：首图、文内图、信息图、分享图
- 插入位置：放在哪个标题或段落之后
- 画面说明：读者看到什么
- 服务观点：这张图支持正文中的哪句话或哪层判断
- prompt：给图像生成工具使用

### 3. 生成图片

如果 Codex 当前环境有 `imagegen` skill 或图像生成工具：

- 直接调用工具生成图片。
- 不要只输出 prompt。
- 每次生成前把画面、风格、构图和限制写清楚。
- 生成后在图文成稿中插入图片路径或 Markdown 图片标记。

如果当前环境没有图像生成能力：

- 输出完整图片清单和 prompt。
- 明确说明“当前环境无法直接生成图片”。
- 不要声称图片已生成。

## Prompt 模板

### 首图/封面图

```text
为一篇公众号文章生成首图。主题：{topic}。
文章核心冲突：{conflict}。
读者情绪：{emotion}。
画面：{scene}。
构图：横版 16:9，主体明确，留出上方或左侧少量干净空间，适合公众号封面裁切。
风格：{style}，克制、有质感、真实光影，避免廉价海报感。
限制：不要出现大段文字，不要出现二维码、水印、品牌 logo，不要伪造真实新闻截图。
```

### 文内场景图

```text
为公众号正文生成文内配图。对应段落观点：{point}。
画面：{scene}。
人物/物体关系：{relationship}。
情绪基调：{emotion}。
构图：横版 4:3，阅读友好，主体清晰，背景不过度复杂。
风格：{style}，细节真实，颜色克制。
限制：不要出现大段文字、二维码、水印、品牌 logo。
```

### 信息图

```text
为公众号文章生成一张信息图。要表达的结构：{structure}。
核心元素：{elements}。
视觉层级：标题区、主体信息区、结论区。
构图：清晰、留白充分，适合手机阅读。
风格：现代编辑设计，干净、有秩序。
限制：文字尽量少，避免密集小字，避免二维码、水印、品牌 logo。
```

## 风格选择

根据文章类型选择风格：

- 商业分析：编辑摄影、办公场景、数据可视化、冷静中性色。
- 科技趋势：真实产品场景、未来感但不过度科幻、清晰光线。
- 社会议题：纪实摄影感、人物背影或手部细节、空间压迫感。
- 生活方式：自然光、真实室内外场景、温和但不甜腻。
- 方法教程：信息图、步骤图、界面抽象图、清晰秩序。
- 情绪故事：电影感、局部特写、光影对比、人物状态。

## 图文成稿格式

推荐输出：

```markdown
# 标题

![首图](生成图片路径或说明)

正文第一段……

[配图：image-01，放在这里是为了说明……]

正文继续……
```

同时附上：

```markdown
## 图片清单

| 文件名 | 类型 | 插入位置 | 服务观点 | Prompt |
| --- | --- | --- | --- | --- |
| cover.png | 首图 | 标题下方 | 表达核心冲突 | ... |
```

## 质量检查

交付前检查：

- 首图独立看是否能理解文章主题。
- 每张文内图是否对应一个具体段落，而不是泛泛好看。
- 图片之间是否构图重复。
- 是否出现了不应有的文字、二维码、水印、logo。
- 是否把未经证实的事件画成了“真实现场”。
- 图文顺序是否自然，不打断阅读。
